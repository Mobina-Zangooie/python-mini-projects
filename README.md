# Python Mini Projects

Small Python projects built while practicing core programming skills: functions, modules, error handling, and graphical interfaces.

## Projects

| Project | Description | Libraries |
|---------|-------------|-----------|
| [calculator](calculator/) | Desktop calculator with the four basic operations, power, and temperature conversion. Persian interface. | `tkinter` |
| [tic-tac-toe](tic-tac-toe/) | Two-player Tic Tac Toe with a dark-themed GUI, turn display, and a "New game" button. | `customtkinter` |

Each project has its own README with run instructions.

## Requirements

Python 3.9 or newer.
